HOLLOW EDITS - Portfolio (Rajan Rathod)

HOW TO USE
1. Double-click index.html to preview locally (internet needed for fonts).
2. To put it online: drag this whole folder onto https://app.netlify.com/drop
   (or upload to Vercel, Cloudflare Pages, GitHub Pages, any hosting).

EDIT TEXT / VIDEOS
- assets/app.js  -> WORKS list at the top (titles, tags, descriptions, YouTube ids)
- index.html     -> all other text (about, services, FAQ, contact)
- assets/style.css -> colors & design (see :root variables)
- media/         -> videos (name.mp4), hover previews (name-preview.mp4), posters (name.jpg)
